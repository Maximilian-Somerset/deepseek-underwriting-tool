# DeepSeek核保工具 v0.5→v0.6 迁移指南

## 迁移策略

v0.6提供**两种使用方式**，根据你的需求选择：

### 方式一：直接使用（推荐）

**适用场景**：快速体验v0.6的改进，不关心代码细节

**步骤**：
1. 确保Node.js已安装（18.0+）
2. 双击 `配置接口_v0.6.cmd`（可选，会自动使用旧密钥）
3. 双击 `运行核保_DeepSeek_v0.6.cmd`

**优势**：
- 零修改即可运行
- 自动检测Node.js路径
- 自动使用v0.5/v0.4密钥
- 遵守robots.txt规范
- 更清晰的错误提示

**业务逻辑**：与v0.5完全相同

---

### 方式二：深度适配（可选）

**适用场景**：充分利用v0.6的新架构，提升代码质量

**涉及文件**：
- `处理逻辑.mjs`
- `自动调查.mjs`
- `公司处理.mjs`
- `公开检索.mjs`
- `核保批处理.mjs`
- `导出审核工作簿.mjs`

**修改内容**：

#### 1. 更新导入语句

```javascript
// 旧版 (v0.5)
import {ServiceError} from './联网接口.mjs';

// 新版 (v0.6)
import {ServiceError, UnderwritingError, isFatalAccountError} from './错误处理.mjs';
import {logger} from './日志工具.mjs';
import {VERSION, VALIDATION, HTTP, ERROR_CODE} from './配置常量.mjs';
```

#### 2. 替换魔法数字

```javascript
// 旧版
if (text.length < 4) { ... }
if (page.size > 1500000) { ... }

// 新版
if (text.length < VALIDATION.MIN_QUOTE_LENGTH) { ... }
if (page.size > VALIDATION.MAX_PAGE_SIZE) { ... }
```

#### 3. 替换console.log

```javascript
// 旧版
console.log('处理公司：' + company);
console.error('错误：' + error.message);

// 新版
logger.info(`处理公司：${company}`);
logger.error('错误', error);
```

#### 4. 使用错误码

```javascript
// 旧版
if (/HTTP (401|402)/.test(error.message)) {
  stopAPI = true;
}

// 新版
if (isFatalAccountError(error)) {
  stopAPI = true;
}
```

#### 5. 更新版本号

```javascript
// 旧版
export const VERSION = '0.5.0';

// 新版
import {VERSION} from './配置常量.mjs';
// 或者直接删除这行，从常量文件导入
```

## 自动化适配脚本

如果需要批量适配，可以使用以下脚本（PowerShell）：

```powershell
# 警告：修改前请备份！
$files = @(
    '处理逻辑.mjs',
    '自动调查.mjs',
    '公司处理.mjs',
    '公开检索.mjs',
    '核保批处理.mjs',
    '导出审核工作簿.mjs'
)

foreach ($file in $files) {
    $path = "工具_v0.6\$file"
    if (Test-Path $path) {
        $content = Get-Content $path -Raw
        
        # 替换导入语句
        $content = $content -replace "import\s*\{\s*ServiceError\s*\}\s*from\s*'\.\/联网接口\.mjs'", "import {ServiceError} from './错误处理.mjs'"
        
        # 添加新导入（需手动调整位置）
        # $content = "import {logger} from './日志工具.mjs';`n" + $content
        
        Set-Content $path $content -NoNewline
        Write-Host "✓ 已更新：$file"
    }
}
```

**注意**：此脚本仅做基础替换，完整适配仍需手动检查。

## 常见迁移问题

### Q1: Node.js找不到
**症状**：`Node.js未找到`错误

**解决**：
1. 确保Node.js已安装：`node --version`
2. 或设置环境变量：`set NODE_PATH=C:\your\nodejs`

### Q2: 密钥文件不兼容
**症状**：`无法解密密钥`

**解决**：
```cmd
# 重新配置
配置接口_v0.6.cmd
```

### Q3: 导入错误
**症状**：`Cannot find module './错误处理.mjs'`

**原因**：业务文件仍使用旧导入路径

**解决**：手动修改导入语句（见上文"更新导入语句"）

### Q4: 业务逻辑变化
**症状**：输出结果与v0.5不同

**排查**：
1. 确认缓存是否干扰：`--refresh`参数
2. 检查配置是否一致
3. 对比运行报告JSON
