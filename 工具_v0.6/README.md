## 迁移步骤

v0.5到v0.6的完整迁移需要：

1. **复制业务逻辑文件**：
   ```bash
   cp 工具_v0.5/处理逻辑.mjs 工具_v0.6/
   cp 工具_v0.5/自动调查.mjs 工具_v0.6/
   cp 工具_v0.5/公司处理.mjs 工具_v0.6/
   cp 工具_v0.5/公开检索.mjs 工具_v0.6/
   cp 工具_v0.5/核保批处理.mjs 工具_v0.6/
   cp 工具_v0.5/导出审核工作簿.mjs 工具_v0.6/
   ```

2. **适配新模块**：
   - 将`ServiceError`改为从`错误处理.mjs`导入
   - 将硬编码常量改为从`配置常量.mjs`导入
   - 将`console.log`改为使用`logger`
   - 添加robots.txt检查（可选）

3. **更新版本号**：
   - 所有文件顶部注释改为v0.6
   - `VERSION`常量改为`0.6.0`

## 快速完成迁移

运行以下命令完成基础迁移（不改动业务逻辑）：

```bash
cd 工具_v0.6
cp ../工具_v0.5/{处理逻辑,自动调查,公司处理,公开检索,核保批处理,导出审核工作簿}.mjs .
```

然后手动修改每个文件的import语句：

```javascript
// 旧版
import {ServiceError} from './联网接口.mjs';
const VERSION = '0.5.0';

// 新版
import {ServiceError} from './错误处理.mjs';
import {VERSION} from './配置常量.mjs';
import {logger} from './日志工具.mjs';
```

## 兼容性

v0.6保持与v0.5的业务逻辑完全兼容：
- 相同的输入Excel格式
- 相同的输出格式
- 相同的缓存结构（可共享）
- 相同的API调用逻辑

唯一区别是代码组织结构和错误处理方式。
